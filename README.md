## 📖 About the Project

> **Jenis Institution** is a premier language training center based in **Pimpri-Chinchwad, Maharashtra**, offering expert-led courses in German, English, IELTS, French, and Overseas Education guidance. Founded in 2010 with **14+ years of excellence** and **10,000+ students trained**.

This is a fully custom, **multi-page responsive website** built as a freelance client project — designed and developed from scratch to replace their outdated Squarespace site with a faster, SEO-optimised, and professionally branded presence.

## 🚀 Deployment

This project is deployed on **Netlify** with automatic CI/CD from GitHub.

```bash
# Clone the repository
git clone https://github.com/shreyassadavarte/jenis-institution.git

# Open locally — no build step needed
cd jenis-institution
open index.html

# Or use Live Server in VS Code for hot reload
```

**Deploy your own fork:**

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start)

1. Push to GitHub
2. Connect repo in Netlify dashboard
3. Set publish directory to `/` (root)
4. Add custom domain → SSL auto-provisions ✅

## 🔧 Local Development

**Prerequisites:** Any modern browser + VS Code (recommended)

```bash
# 1. Clone
git clone https://github.com/shreyassadavarte/jenis-institution.git
cd jenis-institution

# 2. Open in VS Code
code .

# 3. Install Live Server extension (if not already)
#    → Extensions → Search "Live Server" → Install

# 4. Right-click index.html → Open with Live Server
#    → Opens at http://127.0.0.1:5500
```

**No npm, no build tools, no dependencies** — pure HTML/CSS/JS. ✅
